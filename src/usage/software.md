# Lighting Software

While you can use the in-game Lighting Desk to control lights, it's very limited in what it can do and is really
intended for testing out lights, especially when developing content for the mod.

Ideally you need a dedicated lighting software to program your light shows!  
A recommended one is **QLC+**, which is relatively easier to use for those less experienced.  
However here's a list of some popular ones with some community tutorials:

- [QLC+](https://qlcplus.org/) - [tutorial](https://nocticraft.com/qlc-artnet-connection-guide/) (v4 recommended as v5 is less stable)
- [MagicQ](https://chamsyslighting.com/product/magicq-software/) - [tutorial](https://mrdino.es/magicq-artnet-guide/)
- [Dot2](https://www.malighting.com/downloads/products/dot2/) - [tutorial](https://mrdino.es/dot2-artnet-guide/)
- [Eos](https://www.etcconnect.com/eos-software/) - [tutorial](https://mrdino.es/eos-artnet-guide/)
